# Agent instructions

## Agent skills

### Issue tracker

Use GitHub Issues for specifications and tracer-bullet tickets. Read
`docs/agents/issue-tracker.md` before creating, relating, or closing issues.

### Triage labels

Use the repository's canonical triage vocabulary. Read
`docs/agents/triage-labels.md` before applying triage labels.

### Domain docs

Use the single-context domain vocabulary and accepted decisions. Read
`docs/agents/domain.md` before changing public interfaces, identities,
freshness, scheduling, evidence, or execution behaviour.

## Pull requests

Read `CONTRIBUTING.md` before changing the repository or preparing a pull
request. Deliver one independently testable ticket per pull request.
