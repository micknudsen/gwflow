# Triage labels

Use Matt Pocock's default triage vocabulary:

| Role | GitHub label |
| --- | --- |
| Unreviewed intake | `needs-triage` |
| Needs information | `needs-info` |
| Ready for an agent | `ready-for-agent` |
| Ready for a human | `ready-for-human` |
| Will not be implemented | `wontfix` |

The `ready-for-agent` label means that an issue needs no more triage. A parent
specification is context for its implementation tickets, not a request to
implement the entire phase in one change.
